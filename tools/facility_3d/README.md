# Canonical world model

The full walkable 3D world lives on branch `lyra-world-game`:

- Repo: https://github.com/seed0001/Lyras-Movie/tree/lyra-world-game
- Local: `../game/` (`start_game.bat` or `python game/serve.py 8123`)
- Open: http://localhost:8123

This `facility_3d/` folder is a lightweight schematic atlas only. Prefer the game for camera blocking, corridor language, and campus massing.
